# Security

Please report suspected vulnerabilities privately through
[GitHub's reporting form](https://github.com/Excoriate/catppuccin-frappe-prism-zed/security/advisories/new).
Include the affected commit or version, a minimal reproduction, and the impact.
Do not put credentials or private source code in a public issue.

This project distributes theme data and optional settings examples. No stable
release support period or guaranteed response deadline is promised. Ordinary
color and readability problems belong in a public issue.
